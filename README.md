# self-balancing-robot-v1
An autonomous ESP32-S3 (N16R8) self-balancing robot built as a hardware proof-of-concept. Developed on ArduinoIDE using an MPU6050 IMU, DRV8833 driver, and dual BDC TT motors powered by 4x 1.5V batteries. This version focused on upright stability using a basic PID loop before expanding into V2.
